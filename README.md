# Copy Stack — حافظة متعددة النسخ 📋

برنامج بسيط يحل مشكلة أن الحافظة العادية تحفظ آخر نسخة فقط.

**الفكرة:** شغّل البرنامج، ثم انسخ عادي (بالماوس: كليك يمين → Copy، أو Ctrl+C) من أي
صفحات أو برامج مختلفة — **كل نسخة تُحفظ تلقائياً في القائمة**. وبعدين روح للإيميل
أو أي مكان واختر:

- **📋 نسخ الكل للصق** — يجمع كل العناصر في الحافظة، والصقها كلها دفعة واحدة بـ Ctrl+V
- **✅ نسخ المحدد فقط** — اختر عناصر معينة من القائمة (بالضغط مع Ctrl أو Shift) والصقها وحدها
- **نقرة مزدوجة** على أي عنصر — ينسخه وحده فوراً

## التشغيل

### ويندوز (الأسهل)
نقرة مزدوجة على الملف: `run_copy_stack.bat`
(يحتاج [Python](https://www.python.org/downloads/) مثبتاً — عند التثبيت فعّل خيار "Add Python to PATH")

### أي نظام (ويندوز / ماك / لينكس)
```bash
pip install -r requirements.txt
python copy_stack.py
```
> على لينكس تحتاج أيضاً: `sudo apt install xclip`

## المميزات

| الميزة | الشرح |
|---|---|
| مراقبة تلقائية | كل نسخ تسويه من أي برنامج يُضاف للقائمة فوراً باسم "نسخة 1، نسخة 2..." |
| إشعار عند النسخ | يظهر إشعار صغير "نسخة 2 ✅" أسفل الشاشة مع كل نسخة جديدة (قابل للإيقاف) |
| ترقيم عند اللصق | خيار يجعل اللصق يخرج مرقّماً: `1. ... 2. ...` |
| لصق الكل أو المحدد | تجمع كل العناصر أو تختار بعضها فقط |
| اختيار الفاصل | سطر جديد، سطر فارغ، مسافة، أو فاصلة بين العناصر |
| دائماً في المقدمة | النافذة تبقى ظاهرة فوق البرامج (قابلة للإيقاف) |
| إيقاف مؤقت | زر ⏸ يوقف التقاط النسخ الجديدة مؤقتاً |
| حذف ومسح | Delete لحذف المحدد، وزر لمسح القائمة كلها |

## طريقة الاستخدام خطوة بخطوة

1. شغّل البرنامج واتركه مفتوحاً (نافذة صغيرة في المقدمة)
2. تصفح صفحاتك وانسخ أي نص تريده — مرة، مرتين، عشر مرات
3. لاحظ العناصر تتجمع في القائمة بالترتيب
4. افتح الإيميل، ارجع لنافذة البرنامج، اضغط **نسخ الكل للصق** (أو حدد ما تريد ثم **نسخ المحدد فقط**)
5. اضغط Ctrl+V في الإيميل — كل النصوص تُلصق دفعة واحدة ✅
