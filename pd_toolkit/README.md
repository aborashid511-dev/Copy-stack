# أدوات تحويل التفريغ الجزئي (PD) — pC ⇄ mV / dBmV / UHF

مستقلة عن برنامج Copy Stack. تحتاج NumPy فقط (و SciPy اختياريًا).

```bash
pip install -r requirements.txt
python pd_conversion.py                        # عرض توضيحي
python -m unittest -v test_pd_conversion       # الاختبارات
```

> ⚠️ التحويل العام بدون معايرة **تقدير بترتيب المقدار فقط**. التحويل الموثوق يحتاج
> معايرة في نفس المعدّة، ونفس موضع الحساس، ونفس الجهاز.

## الأقسام

| # | الدوال | ماذا تفعل |
|---|---|---|
| 1 | `dbmv_to_mv`, `mv_to_dbmv`, `dbuv_to_dbmv`, `dbm_to_mv` | تحويل الوحدات. dBmV منسوب إلى 1 mV، و dBµV − 60 = dBmV، و dBm قدرة على حمل R (افتراضيًا 50 Ω) تُحوَّل إلى جهد RMS. |
| 2 | `tev_to_pc_generic`, `pc_to_tev_generic` | تقدير TEV → pC بميل عام ≈ 1 µV/pC (Reid, Judd, Duncan 2012). يعيد مجالًا ×10/÷10 **توضيحيًا** وليس قيمة منشورة. |
| 3 | `SiteCalibration` | **الطريقة الموصى بها.** ملاءمة `dBmV = a + b·20log10(q)` من قياسات متزامنة (IEC 60270 + TEV) أو حقن شحنات معلومة، ثم عكسها لتقدير q من قراءة جديدة مع مجال ثقة. |
| 4 | `hfct_charge_pc`, `hfct_scale_factor_pc_per_mv` | HFCT: الشحنة = تكامل التيار، `q = ∫u/Zs dt`. بالوحدات mV و ns و mV/mA ينتج pC مباشرة. يطرح خط الأساس (وسيط أول 50 عينة) قبل التكامل. |
| 5 | `iec60270_peak_mv`, `apparent_charge_from_capacitance` | دائرة IEC 60270: ذروة الخرج لمرشح ممر نطاق مسطح `u = 2(f2−f1)·Zm·q`، و `q = C·ΔV` (‏nF × mV = pC). |
| 6 | `uhf_energy`, `UHFEnergyFit` | UHF: طاقة النبضة ∝ q²، فتُلاءم `E = c·q²` (مربعات صغرى عبر الأصل) ثم `q = √(E/c)`. تُبنى لكل نوع عيب ولكل موضع حساس. |

## مجال الثقة في `SiteCalibration.predict_pc`

بإعطاء قراءة y₀ نحسب `x₀ = (y₀ − a)/b` ثم:

```
Δx = t(1−α/2, dof) · s · √(1 + 1/n + (x₀ − x̄)² / Sxx) / |b|
```

- **‎1** تشتت القراءة الجديدة نفسها، و **‎1/n** عدم اليقين في المقطع a، و **‎(x₀−x̄)²/Sxx**
  عدم اليقين في الميل b. الحد الأخير يكبر كلما ابتعدت القراءة عن مركز بيانات المعايرة،
  ولهذا يتسع المجال عند الاستقراء.
- نستخدم **توزيع t** بدل 1.96 لأن s مقدَّرة من نقاط قليلة. إذا لم تكن SciPy مثبتة
  نحسبه بصيغ مغلقة لـ dof = 1، 2 وبتوسعة Cornish-Fisher لما فوق ذلك (خطأ < 0.005).
- مع `force_linear=True` يُقدَّر a وحده، فيصبح الحد `√(1 + 1/n)` و dof = n − 1.
- المعامل `conf=0.95` حلّ محل `z=1.96` في النسخة الأصلية.

الفرق عمليًا (محاكاة 4000 تجربة، 8 نقاط معايرة بين 20 و 5000 pC، σ = 1.5 dB):

| الشحنة الحقيقية | التغطية الفعلية للمجال القديم | التغطية الفعلية للمجال الجديد |
|---|---|---|
| 300 pC (داخل المدى) | 88.6% | 95.4% |
| 30,000 pC (استقراء) | 78.1% | 95.1% |

أي أن المجال القديم المسمّى "95%" كان متفائلًا، خصوصًا خارج مدى المعايرة.

## تغييرات أخرى عن النسخة الأصلية

- **توافق NumPy:** ‏`np.trapezoid` موجودة فقط من NumPy 2.0، و `np.trapz` أُزيلت لاحقًا،
  فالكود يستخدم المتاحة منهما.
- **التحقق من المدخلات:** القيم الصفرية أو السالبة أو غير المحدودة قبل log/sqrt تعطي
  `ValueError` واضحًا بدل `-inf`/`nan` صامتة. وكذلك عدد نقاط معايرة غير كافٍ، أو شحنات
  كلها متساوية، أو أطوال غير متطابقة، أو طاقة سالبة.
- **R² سالب مع `force_linear=True`** أصبح موثّقًا: يعني أن فرض التناسب الخطي (b=1)
  أسوأ من المتوسط، أي أن البيانات لا تدعمه.

## الحاسبة الميدانية (`pd_field.html`)

نسخة من صفحة الأداة المنشورة على claude.ai، وفيها ستة أقسام:

1. **الدليل:** الاختبارات المناسبة لكل نوع معدة (AIS، GIS، RMU، نهايات الكيبل)، ومكان الحساس، وخطوات المسح، وجدول قراءة النتائج معًا.
2. **المسح:** إدخال قراءات TEV والموجات الهوائية والتلامسية و HFCT لكل طور و UHF، مع تشخيص يجمع الحساسات ويقارن بالمسح السابق لنفس اللوحة.
3. **السجل:** حالة كل لوحة حسب آخر مسح، ومنحنى اتجاه لكل حساس، وتصدير CSV.
4. **الحاسبات:** حسابات TEV والموجات فوق الصوتية و HFCT و UHF، وتحديد المكان (زمن الوصول بين حساسين، والانعكاس داخل الكيبل)، والوحدات و IEC 60270.
5. **أنماط PRPD:** ستة أنماط توضيحية (فجوة، سطحي، كورونا، جزء طافٍ، جسيمات، ضوضاء).
6. **المعايرة والإعدادات:** معايرات موقعية ومجال ثقة 95%، وحدود تقييم قابلة للتعديل.

المعادلات مطابقة لـ `pd_conversion.py` رقمًا برقم. الحفظ (اللوحات والمسوحات والمعايرات) يعمل في النسخة المنشورة فقط.
